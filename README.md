# Прогнозирование оттока клиентов при снижении качества оказания услуги (грузовые железнодорожные перевозки)

Веб-приложение на Streamlit: по наблюдаемым признакам месяца
(объёмы отправок, доля отправок в срок, просрочка, пени, отставленные
поезда) и профилю клиента (сегмент, размер, сценарий качества) оно
выдаёт калиброванную вероятность ухода клиента-грузоотправителя
в следующем месяце, вердикт по порогу F1 и топ-5 SHAP-факторов риска;
при высоком риске выводится рекомендация корректирующего воздействия
№ 2140/р (приоритетный подъём отставленных поездов).

Модель ВКР: панель «клиент × месяц» (имитационный движок Agentklient.sim),
sklearn-пайплайн, вероятности калиброваны (sigmoid, TimeSeriesSplit).

## Файлы приложения

- `web_app_v_01.py` — код приложения (Streamlit);
- `models/zua_model.pkl` — обученная модель (калиброванный пайплайн, порог F1, дерево для SHAP);
- `requirements.txt` — зависимости.

## Инструкция использования приложения

1. Перейти в браузере по ссылке https://zavjuly.streamlit.app;
2. Выбрать сегмент клиента (loyal / sensitive / at_risk), размер
   (small / medium / large) и сценарий качества (baseline — норма,
   quality_decline — стресс сети, доля задержек 32 %);
3. Задать показатели месяца: отправки, вагоны, доля отправок в срок,
   средняя просрочка (сут), доля пени в плате, отставленные поезда;
4. Нажать кнопку «Predict» — внизу появится вероятность оттока,
   вердикт по порогу и факторы риска.

Локальный запуск: `streamlit run web_app_v_01.py` (модель ищется в
`models/zua_model.pkl`; путь можно переопределить переменной окружения
`ZUA_MODEL_PATH`).
